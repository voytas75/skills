TEXT PRESENTATION / SKILL

Text presentation techniques

Choose the form that best exposes the information structure.

01 · Definition in one sentence

Term — inputs → function or decision.

Keep the scope; do not remove what the term governs.

07 · Decision tree

Compliant?
├ yes → allow
└ no  → block / remediate

Use when a condition changes the next path.

05 · Comparison table

AttributeAB
Managedyesno
PolicycompliantMFA

Use for repeated comparable attributes.

26 · Status symbol + word

● OK · ▲ WARN · ✖ FAIL · ○ N/A

Never encode status using color alone.

33 · Command + expected output

> command --check
Status : OK

Separate input from output; use grounded output.

Governing rule: minimize reading effort without losing conditions, exceptions, units, scope, or relationships.
