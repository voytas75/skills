# text-presentation-techniques

Complete Agent Skill for selecting and applying text-presentation techniques in technical documents, reference sheets, procedures, reports, dashboards, and operational communication.

## Source basis

Built from the supplied HTML reference **“Techniki prezentacji tekstu — ściągawka (v3)”**. The skill retains its five categories and all 47 numbered techniques, along with the stated limits and visual principles. It converts the reference into an operational skill with selection rules, quality checks, and an interactive example.

## Five categories

1. Conciseness
2. Flow
3. Structure
4. Numbers and status
5. Commands and code

## Use

Load `SKILL.md` as the entry point. Read only the relevant reference for the task. The HTML example is illustrative and self-contained; it is not a replacement for the source catalog or the skill rules.
