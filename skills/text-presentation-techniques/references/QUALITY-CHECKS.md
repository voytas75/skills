# Quality Checks

## Semantic integrity
- [ ] The communication task and audience are clear.
- [ ] Scope, actor, action, object, conditions, and exceptions are preserved.
- [ ] Sequence and branch conditions are unambiguous.
- [ ] Causal claims are supported by a known mechanism.
- [ ] Abbreviations are defined at first use.
- [ ] Symbols and notation have a legend when needed.
- [ ] Cross-references resolve to existing content.

## Structure and selection
- [ ] The selected technique matches the information shape.
- [ ] A table is used for comparable attributes, not merely as decoration.
- [ ] A decision tree has all material branches.
- [ ] A timeline is used only when time matters.
- [ ] Shared context has an unambiguous scope.
- [ ] Combined techniques add distinct value rather than repetition.

## Numbers and charts
- [ ] Units, denominators, periods, and precision are explicit.
- [ ] Numeric values are aligned consistently.
- [ ] Thresholds are sourced and ranges are complete/non-overlapping.
- [ ] Sparkline/chart points come from actual data.
- [ ] Chart scale and baseline are appropriate.
- [ ] Chart has a text equivalent or accessible description.
- [ ] Illustrative data is labeled as illustrative.
- [ ] Status direction and desirability are not conflated.

## Visual system
- [ ] Category color mapping is consistent.
- [ ] Color is not the only information carrier.
- [ ] Contrast works in light and dark modes.
- [ ] Emphasis is limited and intentional.
- [ ] Typography and spacing match the density mode.
- [ ] The hierarchy is visible without relying on color alone.

## Commands and code
- [ ] Commands are syntactically valid for the stated shell/platform/version.
- [ ] Code is distinguished from prose.
- [ ] Required, optional, alternative, and repeatable syntax is explained.
- [ ] Input and expected output are visually distinct.
- [ ] Expected output is grounded, not fabricated.
- [ ] Commands are tested before being presented as production-ready.

## Rendering and delivery
- [ ] Mobile layout does not clip critical content.
- [ ] Tables remain usable at narrow widths.
- [ ] Print/PDF output has been checked for page breaks and legibility.
- [ ] Interactive controls are keyboard accessible.
- [ ] Content remains understandable if color or JavaScript is unavailable.
- [ ] No unnecessary visual decoration increases reading effort.
