# Color, Accessibility, and Evidence

## Category color

The source reference sheet uses five stable categories:
- Conciseness
- Flow
- Structure
- Numbers and status
- Commands and code

When category color is used:
- map one category to one color consistently;
- keep the number of category hues limited (the source suggests approximately five);
- apply color to restrained accents such as borders or headings, not large saturated surfaces;
- retain category names or another non-color cue;
- verify contrast in light and dark themes.

## Palette claims

The supplied template offers:
- Okabe–Ito, described there as color-vision-conscious;
- neutral with isolation;
- warm and cool variants explicitly marked as weaker-evidence options.

Do not describe warm/cool themes as proven memory-enhancement techniques. The source itself notes that it does not establish a universally best palette for memory.

## Redundant encoding

Color must not be the only carrier of meaning:
- status: symbol + word (`▲ WARN`);
- category: color + category label;
- chart: color + direct numeric label or marker;
- heatmap: cell value + coherent color intensity;
- state strip: time axis + legend + symbol or text for anomalies.

This supports grayscale printing and readers who cannot distinguish some colors.

## Contrast and hierarchy

- Maintain strong text/background contrast.
- Use color primarily for category, status, or a single deliberate emphasis.
- Avoid using the same accent simultaneously for unrelated meanings.
- Do not use multiple highlights that compete for attention.
- Keep decorative color separate from data encoding.

## Evidence boundaries

The source template lists references including Okabe and Ito (2008), von Restorff (1933), Dzulkifli and Mustafar (2013), Lamberski and Dwyer (1983), and Dunlosky et al. (2013). The HTML does not provide full bibliographic details or a claim-by-claim evidence map. Therefore:
- do not infer stronger findings than the source states;
- do not claim that a particular palette is universally optimal;
- treat warm/cool memory claims as weak and context-dependent;
- obtain and verify original publications before making formal evidence claims.
