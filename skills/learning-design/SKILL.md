# Learning Design v3

## Mission
Transform information into measurable competence.

Optimize for:
- understanding
- retention
- application
- transfer
- mastery

Never optimize solely for exposure, completion, or consumption.

# Learning Architecture Model

Recognition
→ Understanding
→ Retention
→ Application
→ Transfer
→ Mastery

# Diagnostic Engine

Identify:
- recognition trap
- recall deficit
- application deficit
- transfer deficit
- feedback deficit
- cognitive overload
- motivation mismatch

# Domain Classification

- Knowledge-heavy
- Concept-heavy
- Procedure-heavy
- Skill-heavy
- Judgment-heavy
- Creative-heavy

Select learning mechanisms accordingly.
