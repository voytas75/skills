# Assessment framework

## Alignment
For every learning outcome, define an assessment that samples the same performance, conditions, quality, and independence level.

Outcome pattern:
`Given [conditions], learner can [action] to [quality threshold] with [allowed support].`

## Assessment types
- **Diagnostic:** establishes starting point and misconceptions.
- **Formative:** informs the next teaching or practice decision.
- **Summative:** judges achievement against predefined criteria.
- **Authentic:** resembles the real task or environment.
- **Transfer:** changes context, constraints, or surface features while preserving the underlying capability.

## Evidence selection
Prefer direct performance for practical skills. Use recall or explanation when those are the intended outcomes or useful supporting evidence. Completion, time spent, confidence, and satisfaction are not sufficient evidence of competence.

## Rubric template

| Criterion | Not yet demonstrated | Developing | Meets target | Exceeds target |
|---|---|---|---|---|
| Accuracy | Material errors | Partial / inconsistent | Meets defined accuracy threshold | Accurate with justified checks |
| Process | Cannot complete / unsafe sequence | Completes with prompts | Correct independent process | Efficiently handles edge cases |
| Independence | Full guidance required | Some prompts required | Performs with allowed resources only | Self-corrects and explains choices |
| Transfer | Cannot adapt | Adapts with substantial help | Handles specified novel variation | Generalizes across varied contexts |

Customize criteria to the outcome. Do not use generic rubric dimensions if they do not matter.

## Pass criteria
Specify thresholds before assessment. Examples:
- all critical safety steps completed;
- at least 8 of 10 items correct, if that threshold is justified by the assessment purpose;
- artifact meets every mandatory acceptance criterion;
- task completed independently using only allowed resources.

Avoid arbitrary universal percentages. Safety-critical outcomes may require zero critical errors.

## Reporting
For each outcome report:
- status: not assessed / not yet demonstrated / developing / meets target / exceeds target;
- evidence and conditions;
- criteria met and unmet;
- confidence or limitations;
- next action.

Do not infer a level from a single weak proxy. If the sample is insufficient, state that.
