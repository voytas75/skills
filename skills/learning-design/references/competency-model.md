# Competency model

Use criterion-referenced levels. The level describes demonstrated performance on a specified outcome, not a permanent trait of the learner.

| Level | Label | Evidence |
|---|---|---|
| L0 | Not assessed | No relevant performance evidence |
| L1 | Recognizes | Identifies terms, components, or correct options in familiar contexts |
| L2 | Explains | Describes principles, relationships, or rationale accurately |
| L3 | Performs with guidance | Completes task using prompts, examples, or step-by-step support |
| L4 | Performs independently | Meets the rubric in the stated context with allowed resources |
| L5 | Transfers and adapts | Performs in a meaningfully changed context, selects methods, and handles relevant variation |

## Rules
- Do not automatically progress by time spent or lesson completion.
- Define task-specific evidence for each level.
- Not every outcome needs all six levels.
- L5 requires a genuinely changed context, not merely different numbers in an identical exercise.
- A learner may be L4 for one subskill and L2 for another. Report per outcome, not as one global score.
- Reassess after targeted practice.
