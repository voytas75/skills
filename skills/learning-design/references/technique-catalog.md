# Technique catalog

Each technique is a tool, not a compulsory stage. Select by outcome, prior knowledge, task complexity, and evidence of the current gap.

| Technique | Purpose | Use when | Cautions / limits |
|---|---|---|---|
| Retrieval practice | Strengthen accessible recall and diagnose gaps | Knowledge must be recalled without source | Include correction; retrieval should be appropriately difficult |
| Spaced practice | Revisit learning over time | Retention beyond one session matters | No universal interval; adapt to performance and horizon |
| Worked examples | Reduce unproductive search while learning a new procedure | Novice learning a complex task | Follow with completion problems and independent practice |
| Faded guidance | Move from supported to independent performance | Learner can perform parts with help | Fade based on evidence, not arbitrary lesson count |
| Deliberate practice | Improve a specific subskill through targeted effort and feedback | Performance can be decomposed and corrected | Requires clear criteria and feedback; repetition alone is insufficient |
| Interleaving | Improve discrimination and method selection | Similar problem types are easily confused | Can overload novices before basic patterns are established |
| Elaboration | Build links and causal explanations | Conceptual understanding is needed | Check reasoning; plausible elaborations can be wrong |
| Self-explanation | Make reasoning visible | Learner can explain steps or principles | Prompt for evidence and identify gaps |
| Dual coding | Coordinate verbal and visual representations | Spatial, structural, or relational content | Visuals should complement, not decorate or duplicate |
| Concept mapping | Expose relationships and misconceptions | Systems and concepts have meaningful links | Require labeled propositions; avoid clutter |
| Scenario-based learning | Practice contextual judgment | Decisions depend on context and constraints | Scenarios must represent relevant conditions |
| Project-based learning | Integrate capabilities into a deliverable | End-to-end production is an outcome | Include explicit instruction and individual evidence |
| Reflection | Improve monitoring and future strategy | After an attempt or project | Use specific prompts; vague reflection has low diagnostic value |
| Teach-back | Reveal gaps in explanation and organization | Explanation is part of the outcome or a useful diagnostic | Fluent explanation alone does not prove execution |
| Mnemonics | Encode arbitrary facts or sequences | Recall cues are useful | Not a substitute for understanding or application |
| Analogies | Connect unfamiliar ideas to known structures | A concept has a useful structural parallel | State where the analogy breaks down |

## Selection procedure
1. Name the diagnosed gap.
2. Select one primary method that directly addresses it.
3. Add a secondary method only for a distinct need (e.g. visual model plus retrieval).
4. Define the learner action and expected evidence.
5. Define the limitation and a way to check for misconception.
6. Reassess and adapt.

## Common distinctions
- **Retrieval practice** is the family of activities that require recall; **active recall** is a common form.
- **Practice** is not automatically deliberate practice. Deliberate practice targets a defined performance component with feedback and correction.
- **Exposure** is not learning evidence.
- **Completion** is not mastery evidence.
- **Confidence** is not accuracy.
