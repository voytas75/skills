# Domain-to-method mapping

Use this as a decision aid, not a rigid taxonomy. Most real capabilities combine demands.

| Demand | Diagnose with | Teach / model | Practice | Assess |
|---|---|---|---|---|
| Factual | Closed-book recall, discrimination | Chunking, concise explanation, examples | Retrieval, flashcards, spaced review | Accurate recall after delay |
| Conceptual | Explain, predict, compare | Worked examples, analogy, concept map | Elaboration, contrasting cases | Explain and predict unfamiliar examples |
| Procedural | Reconstruct steps, perform sequence | Demonstration, worked example | Guided then independent repetition | Correct execution under stated conditions |
| Technical | Complete authentic task, troubleshoot | Demo, lab walkthrough, annotated example | Deliberate practice, labs, error diagnosis | Independent task and troubleshooting |
| Judgment | Choose and justify action | Cases, decision criteria, counterexamples | Scenarios, interleaving | Decision quality and rationale in new case |
| Creative | Generate and refine artifact | Exemplars, constraints, critique criteria | Project iterations, feedback | Quality, originality within brief, rationale |
| Integrated | Decompose into subskills | Sequence models and demonstrations | Combined projects and realistic scenarios | End-to-end performance plus transfer |

## Selection rules
- Diagnose the performance, not merely the subject label.
- If prerequisite knowledge is weak, repair it before complex independent practice.
- For novices facing high element interactivity, use clear instruction and worked examples before discovery-heavy tasks.
- Fade guidance as performance becomes reliable.
- Use interleaving after initial orientation when the learner must distinguish similar methods.
- Use projects only when integration or authentic production is an intended outcome; projects alone do not guarantee learning.
- Use visual representations when they clarify relationships, not because a learner is assigned a "visual" style.
- Use mnemonics for arbitrary facts or sequences; do not replace conceptual understanding with memory tricks.
