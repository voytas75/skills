# Diagnostic framework

## Purpose
Identify the most likely learning or performance barrier before prescribing an intervention. Diagnosis is provisional and should be revised when new evidence appears.

## Diagnostic sequence
1. Clarify the target performance and its conditions.
2. Inspect prior work, examples, or learner evidence.
3. Ask for a brief explanation or prediction where conceptual knowledge matters.
4. Ask for a representative performance where execution matters.
5. Classify the error pattern.
6. Check task clarity, resources, environment, time, and accessibility.
7. Select the smallest intervention that tests the leading explanation.

## Gap taxonomy

| Gap | Observable signal | Diagnostic probe | Likely intervention |
|---|---|---|---|
| Prerequisite | Fails foundational subtask | Test prerequisite directly | Repair foundation |
| Factual | Cannot retrieve or distinguish facts | Closed-book recall / discrimination | Retrieval + spaced practice |
| Conceptual | Gives incorrect explanation or prediction | Explain why; predict a changed case | Alternative explanation, examples, concept map |
| Procedural | Knows purpose but loses sequence | Reconstruct or execute steps | Worked example, checklist, guided practice |
| Fluency | Correct but slow or inconsistent | Repeat comparable task under normal conditions | Targeted practice and feedback |
| Judgment | Selects unsuitable action | Present contrasting scenarios | Decision criteria, cases, interleaving |
| Transfer | Succeeds only in familiar format | Change context, constraints, or surface features | Varied examples and transfer tasks |
| Metacognitive | Misjudges confidence or readiness | Compare confidence with actual performance | Calibration and evidence review |
| Feedback | Repeats same error after practice | Inspect feedback quality and uptake | Specific feedback and retry |
| Environment | Tool, access, or unclear instructions block performance | Verify environment and task conditions | Remove blocker; do not prescribe more study |
| Overload | Loses track of interacting elements | Reduce task complexity temporarily | Segment, model, scaffold, then reintegrate |

## Evidence rules
- One failure is a signal, not a diagnosis.
- Distinguish an incorrect answer from an unclear prompt or unavailable resource.
- Ask for the learner's reasoning when the answer alone cannot reveal the cause.
- Do not infer motivation, intelligence, disability, or psychological state from performance.
- Record confidence separately from correctness.
- Label hypotheses as hypotheses until tested.

## Diagnostic output
Return:
- target performance;
- evidence observed;
- gap classification;
- alternative explanations / unknowns;
- selected intervention;
- reassessment task and success criterion.
