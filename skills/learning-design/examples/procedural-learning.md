# Example: procedural learning

## Request
"Help a new employee learn a repeatable account-provisioning procedure."

## Outcomes
Given an approved request and the documented environment, the employee can complete the procedure, validate each required control, record evidence, and escalate exceptions without bypassing policy.

## Design
1. Verify prerequisites, permissions, and safety constraints.
2. Demonstrate one complete case while explaining decision points.
3. Provide a checklist and guided practice on a test account.
4. Fade prompts after correct execution.
5. Assess independent execution on a separate test case.
6. Introduce an exception scenario and require correct escalation.

## Assessment
Critical controls must all pass. Record process accuracy, evidence quality, independence, and exception handling. Never use a live account for initial practice unless the environment and authorization explicitly permit it.
