# Example: conceptual learning

## Request
"Teach me the difference between authentication and authorization."

## Outcome
Given a new access-control scenario, the learner can distinguish identity verification from permission evaluation and explain the order and relationship accurately.

## Design
1. Give a concise explanation and one worked scenario.
2. Use a comparison table with purpose, question answered, and typical evidence.
3. Ask the learner to classify several contrasting scenarios without looking.
4. Provide feedback on each misconception.
5. Ask the learner to explain a new scenario in their own words.
6. Revisit with delayed retrieval if long-term recall matters.

## Assessment
Pass when the learner correctly classifies all critical scenario elements and explains why authentication success does not imply authorization success. A memorized definition alone is insufficient.
