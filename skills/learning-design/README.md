# Learning Design Skill

Version: 2.0.0<br>
Author: voytas75<br>
Format: Agent Skills (`SKILL.md` with YAML frontmatter)

## Contents
- `SKILL.md` — activation, workflow, output contract, quality gates.
- `references/` — method catalogue, diagnosis, assessment, competency, retention, and evidence notes.
- `assets/` — reusable learning-path and assessment templates.
- `examples/` — technical, conceptual, and procedural learning examples.

## Install
Copy the `learning-design/` directory into the skills directory supported by your agent client.

## Validation
Check the package with the official Agent Skills reference validator (`skills-ref validate learning-design`) where available. Structural validation does not establish instructional effectiveness; test representative tasks in the target client.
