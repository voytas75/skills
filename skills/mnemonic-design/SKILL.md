# Purpose

Transform information into durable memory traces.

The goal is NOT explanation.

The goal is NOT summarization.

The goal is maximizing:

- memorability
- recall speed
- retention duration
- retrieval accuracy

while preserving correctness.

# Core Principle

Information becomes memorable when it is transformed through one or more memory mechanisms:

1. Imagery
2. Association
3. Narrative
4. Spatiality
5. Emotion
6. Pattern
7. Retrieval

The skill must identify which mechanisms will create the strongest memory trace.

# Memory Design Process

For every request:

Step 1:
Analyze information structure.

Determine:

- facts
- concepts
- sequences
- procedures
- relationships
- numbers
- abstractions

Step 2:
Determine memory difficulty.

Classify:

LOW
MEDIUM
HIGH

memorization complexity.

Step 3:
Select memory mechanisms.

Choose the smallest effective combination.

Step 4:
Generate memory design.

Step 5:
Score memory strength.

If score is weak:
improve automatically.

# Memory Mechanisms

## Imagery

Transform concepts into vivid visual objects.

Prioritize:

- oversized objects
- impossible scenarios
- exaggerated features
- vivid colors
- movement

Avoid generic imagery.

## Association

Connect new information to existing knowledge.

Use:

- analogies
- metaphors
- familiar objects
- real-world systems

Preference:

known -> unknown

## Narrative

Encode information inside events.

Prefer:

- cause and effect
- character interaction
- conflict
- action

## Spatial

Attach knowledge to locations.

Use:

- memory palace
- journey method
- room mapping

## Emotional

Increase retention through emotional amplification.

Use:

- humor
- surprise
- absurdity
- achievement

## Pattern

Compress information into recognizable patterns.

Use:

- chunking
- grouping
- hierarchy
- acronym construction

## Retrieval

Design recall triggers.

Generate:

- cues
- challenge questions
- prompts
- memory hooks

# Technique Selection

## Lists

Prefer:

- story chains
- memory palace
- journey method
- peg systems

## Procedures

Prefer:

- narrative encoding
- location encoding

## Abstract Concepts

Prefer:

- metaphor
- personification
- analogy

## Numbers

Prefer:

- major system
- peg systems
- PAO

## Dense Knowledge

Prefer:

- chunking
- conceptual clustering
- layered encoding

# Memory Strength Checklist

Rate 1-10:

- vividness
- novelty
- emotional impact
- association strength
- retrieval ease

If below Strong:
redesign automatically.
