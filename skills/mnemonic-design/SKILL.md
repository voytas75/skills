# Mnemonic Design

## Purpose

Mnemonic Design transforms information into memory-friendly representations.

The primary objective is:

- maximize memorability
- maximize recall speed
- maximize retention duration

The objective is NOT:

- explanation
- visualization
- summarization
- teaching

Those objectives belong to other skills.

Mnemonic Design focuses exclusively on memory architecture.

---

# Use When

Use this skill when the user asks to:

- remember information
- memorize information
- learn facts quickly
- retain concepts
- create memory aids
- prepare for exams
- remember procedures
- remember terminology
- remember vocabulary
- remember numbers
- remember sequences

---

# Do Not Use When

Do not use as primary skill when user asks:

- explain something
- visualize something
- create diagrams
- organize knowledge
- design a learning curriculum

Understanding → Visual Knowledge Design

Learning Process → Learning Design

Knowledge Structure → Knowledge Structure Design

---

# Core Principle

People rarely remember information.

They remember:

- images
- stories
- locations
- emotions
- patterns
- surprising events

Transform abstract knowledge into memorable experiences.

Never memorize facts directly if they can be transformed.

---

# Memory Mechanisms

## 1. Imagery

Create vivid mental images.

Prefer:

- large objects
- impossible objects
- exaggerated size
- strong color
- movement

## 2. Association

Attach unknown information to known information.

Rule:

Known → Unknown

## 3. Narrative

Encode information in stories.

## 4. Spatial Memory

Use locations.

Techniques:

- Memory Palace
- Method of Loci
- Journey Method
- Room Mapping

## 5. Emotion

Increase retention through:

- humor
- surprise
- absurdity
- success
- danger

## 6. Pattern Recognition

Create structure.

Techniques:

- chunking
- hierarchy
- grouping
- categorization
- acronym formation

## 7. Retrieval

Design future recall.

Create:

- cues
- prompts
- challenge questions
- flashcard-style triggers

---

# Memory Design Workflow

1. Analyze Content
2. Assess Memorization Difficulty
3. Select Memory Mechanisms
4. Generate Memory Architecture
5. Score Strength

---

# Memory Strength Score

Rate:

- Vividness (1-10)
- Novelty (1-10)
- Emotional Impact (1-10)
- Association Strength (1-10)
- Retrieval Ease (1-10)

Interpretation:

- 40-50 Exceptional
- 30-39 Strong
- 20-29 Acceptable
- Below 20 Redesign
