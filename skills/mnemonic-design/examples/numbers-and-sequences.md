# Example: Numeric Encoding — Major System

**Target:** 32.

Using the common Major System mapping: 3 → M and 2 → N. Add vowels to form a word such as "moon" (M-N consonant sequence).

**Cue:** imagine a bright moon shaped like a large number 32.<br>
**Decode:** moon → M-N → 3-2 → 32.

For longer numbers, declare the consonant mapping, split into manageable groups, avoid ambiguous sounds, decode every group, and preserve leading zeros, signs, and decimal points separately.
