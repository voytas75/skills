# Example: Technical Concepts — Contrastive Cues

## Authentication vs authorization
- Authentication: establishing who or what an entity is.
- Authorization: determining what an authenticated entity may do.

**Authentication cue:** an ID badge being scanned.<br>
**Authorization cue:** a gate checking the badge's access rights.

| Term | Cue | Recall question |
|---|---|---|
| Authentication | ID badge / identity | Who or what are you? |
| Authorization | Gate / permission | What may you access or do? |

Both may occur in one access flow. Successful authentication does not prove access is authorized.

**Test:** A system verifies identity — which concept? A system checks resource permissions — which concept? Can a user be authenticated but not authorized?<br>
