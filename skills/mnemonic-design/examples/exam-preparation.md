# Example: Exam Recall Pack

Use one atomic card per distinction, plus a comparison prompt.

| Front | Back | Cue |
|---|---|---|
| Define concept A | Canonical definition | Distinctive cue A |
| Define concept B | Canonical definition | Distinctive cue B |
| What separates A and B? | Explicit distinguishing feature | Contrast pair |

## Practice loop
1. Attempt all fronts without looking.
2. Check against source.
3. Mark correct / partial / incorrect.
4. Redesign cues for repeated confusions.
5. Schedule delayed review based on results.

Do not infer exam readiness from card familiarity. Include mixed questions, application tasks, and timed practice when these reflect the actual exam.
