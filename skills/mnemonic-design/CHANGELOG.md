# Changelog

## 2.0.0 — 2026-11-09
### Added
- Diagnostic workflow for target, retrieval mode, deadline, and learner context.
- Technique selection based on information structure and required recall.
- Explicit cue-to-answer mapping and ambiguity/interference checks.
- Retrieval practice with correction and retesting.
- Adaptive spaced-review planning.
- Validation states distinguishing untested from tested mnemonics.
- Modular references, templates, and examples.
### Changed
- Replaced subjective 50-point strength score with quality gates and retrieval evidence.
- Reframed vividness, novelty, and emotion as optional design features.
- Clarified boundaries between memory aids, understanding, learning design, and practical performance.
### Removed
- Categorical rule to transform every fact.
- Unsupported numerical thresholds for mnemonic quality.
