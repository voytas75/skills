# Retrieval Practice and Feedback

Require an answer before revealing it. Rereading, recognition, and familiarity do not establish successful recall.

## Prompt design
| Future requirement | Prompt |
|---|---|
| Definition | Define X in your own words. |
| Exact term | Write the canonical term for this meaning. |
| Vocabulary | Given the word, produce meaning; reverse if needed. |
| Ordered list | Reconstruct all items in order. |
| Number | Decode image to exact digits. |
| Distinction | Which feature separates A from B? |
| Procedure | State next step and condition. |
| Relationship | Explain how A affects B and when. |

## Feedback loop
1. Present one prompt.
2. Wait for unaided response.
3. Compare with canonical answer and accepted variants.
4. Classify correct / partial / incorrect / too slow (if speed matters).
5. Show correct answer and missing detail.
6. Ask learner to restate or reconstruct.
7. Schedule later retrieval.

Do not mark correct because the answer resembles the story.

## Error taxonomy and intervention
- Omission → strengthen coverage/chunk structure.
- Substitution or confusion → contrastive cue.
- Order error → strengthen transition/loci order.
- Precision error → exact-answer prompt and source check.
- Cue failure → simplify and rehearse cue.
- Mapping failure → make mapping explicit.
- Misconception → explain and correct before mnemonic practice.

For each memory unit include direct recall, discrimination if needed, and delayed recall if retention matters. Do not claim validation before observing actual responses.
