# Mnemonic Validation Framework

## States
- **Designed:** cue created and source fidelity checked.
- **Untested:** no learner retrieval attempt observed.
- **Tested:** at least one attempt observed.
- **Needs revision:** error or ambiguity requires redesign.
- **Validated for stated task:** explicit criteria met on supplied test; not a guarantee of future retention.

## Quality review
**Source:** correct answer, exact order/spelling/units/sign/exceptions, no invented facts.<br>
**Cue:** explicit mapping, distinct from similar items, no misleading metaphor, recoverable.<br>
**Retrieval:** unaided prompt, accurate answer key, accepted variants, feedback.<br>
**Retention:** delayed review when needed, schedule adapted to evidence, claims limited to evidence.

## Evidence record
| Date/interval | Prompt | Response | Result | Error | Next action |
|---|---|---|---|---|---|

Do not invent test data or report a score without actual results and an explicit scoring rule.

## Acceptance criteria
Define before testing: all items in order; exact number with no digit errors; concepts distinguished without substitution; key stages recalled. For high-consequence facts, mnemonic recall alone is insufficient; verify against authoritative source.
