# Technique Selection

## Decision procedure
1. Determine required behavior: recognition, cue-based recall, free recall, exact reproduction, ordered recall, discrimination, explanation, or execution.
2. Classify material: meaningful/arbitrary, concrete/abstract, isolated/relational, ordered/unordered, verbal/visual/numeric/procedural.
3. Estimate error consequence, similarity, exactness, retention horizon.
4. Select the simplest suitable method.
5. Add retrieval and feedback.
6. Validate against source.

## Selection matrix
| Target | Starting choice | Add / caution |
|---|---|---|
| Meaningful concept | Explanation + retrieval | Mnemonic only for arbitrary details |
| Sound-to-meaning | Keyword + image | Check pronunciation and mapping |
| Short sequence | Link/story chain | Chunking |
| Long sequence/speech | Loci/Journey | Stable route and rehearsal |
| Recall by position | Peg system | Learn mapping first |
| Exact numeric sequence | Major System / PAO | Decode every digit |
| Similar concepts | Contrastive mnemonic | Encode distinguishing feature |
| Hierarchy | Meaningful chunking | Concept map if relationships need understanding |
| Procedure | Stage chunks + action cues | Real task practice required |
| Exam facts | Atomic retrieval cards | Adaptive spaced review |

## Constraints
- Do not use a memory palace for a tiny list if direct recall is simpler.
- Do not use ambiguous acronyms.
- Do not use metaphor for exact operational behavior without stating limits.
- Do not substitute mnemonic for meaningful explanation.
- Do not use numeric encoding unless it can be decoded unambiguously.
- Avoid competing mnemonics for one target unless requested or needed after failure.
- High-consequence facts require source verification and exception handling.

State selected method, why it fits, one limitation, and what will be tested.
