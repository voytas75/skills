# Mnemonic Technique Catalog

## Association and imagery

### Keyword Method
Connect an unfamiliar word to a familiar-sounding keyword, then create an image linking keyword and meaning. Use for vocabulary and arbitrary terminology. Check pronunciation and semantic mapping; sound similarity can be weak.

### Direct imagery
Create a concrete image for the target or defining feature. Use for concrete objects and attributes. Abstract terms may need explanation or a structured analogy.

### Personification / metaphor
Represent an abstract concept as an agent or familiar system. State what maps and what does not; metaphors are partial models.

## Sequence methods

### Link Method / Story Chain
Connect each item to the next through an interaction. Use for short ordered lists. Rehearse direction; a broken link may disrupt later recall.

### Journey / Method of Loci
Place distinctive images at ordered locations on a familiar route. Define route and direction, place images, rehearse, then test unaided recall. Requires stable loci and practice; avoid overloaded or similar locations.

### Peg System
Associate targets with a pre-learned ordered set of pegs (e.g. number-rhyme or number-shape). Use for recall by position. Learn and consistently apply the peg mapping.

## Number encoding

### Major System
Encode digits as consonant sounds, then add vowels to form words/images. Common mapping:
| Digit | Sounds |
|---:|---|
| 0 | s, z, soft c |
| 1 | t, d, th |
| 2 | n |
| 3 | m |
| 4 | r |
| 5 | l |
| 6 | j, sh, soft ch, zh |
| 7 | k, hard c, hard g, q |
| 8 | f, v |
| 9 | p, b |

Encode sounds, not spelling. Declare the convention, chunk long strings, and decode to exact digits. Pronunciation/language may create ambiguity.

### Person-Action-Object (PAO)
Map number groups to a person, action, and object, then combine them into one interacting scene. Requires a stable learned dictionary; do not invent a full dictionary without confirming language and mapping.

## Structural methods

### Chunking
Group related elements into meaningful units. Preserve exact sequence and semantic boundaries.

### Acronyms / initial-letter mnemonics
Use initials to form a cue. Include a decoding key; initials can collide or fail to preserve order.

### Contrastive mnemonics
Encode the feature distinguishing similar items, preferably as a pair. Verify against authoritative definitions.

### Dual Coding
Pair concise verbal information with a meaningful image or spatial structure. Avoid decorative or redundant imagery.

## Retrieval methods
- **Retrieval Cards:** prompt one answer before revealing the back.
- **Blank Reconstruction:** recreate a sequence/diagram from memory, then compare with source.
- **Spaced Retrieval:** repeat retrieval after delays, adapting to performance.
