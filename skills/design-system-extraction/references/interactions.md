# Interaction discovery
Default: all visible controls and controls revealed by safe actions are in scope. Use isolated, unauthenticated browser contexts. Record accessible name/role, initial state, source action/result, target action/result, URL/focus/keyboard changes, reversibility, evidence. Test menu open/close, search reveal/close, disclosures, tabs, local toggles, focus order and keyboard activation where present.

Do not submit real forms, trigger payments, mutate accounts, post data, or perform destructive actions. Navigation may be inspected without completing sensitive transactions. Reset/reload after reversible tests and verify initial state. Unsafe/unavailable behavior => `NOT_TESTED` with reason; never call a local click PASS proof of full service behavior. `functional_fidelity: PASS` requires complete required control coverage, source and target behavior equivalence, keyboard/focus states in scope, and no required FAIL/NOT_TESTED. Partial successful actions => PARTIAL, not PASS.
